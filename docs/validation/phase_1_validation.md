# Phase 1 validation

Current validation establishes prototype-model sanity: finite outputs, bounded/non-negative shaft speed, correct RPM conversion, starter behaviour, atmospheric domain checks, and successful one-step causal integration. The test suite is not an engine certification, calibration campaign, or proof of mission reliability.

Required future validation includes traceable Rotax data, controlled operating points, transient measurements, propeller data, uncertainty quantification, and independently reviewed acceptance criteria. Until then, all surrogate values and performance outputs remain engineering estimates.
