# Module 01 — Configuration Management

## YAML Configuration Files (`configs/`)
- `acquisition_config.yaml`: Pipeline timeouts, buffer sizes, storage paths.
- `demonstration_can_mappings.yaml`: Representative CAN ID bit mappings (0x101, 0x102, 0x103).
- `engine_profiles/representative_4stroke_piston.yaml`: Configurable 4-cylinder representative engine profile.
- `limits/sensor_validity_limits.yaml`: Tier 2 plausibility ranges & Tier 6 max rate-of-change limits.
- `limits/operational_metadata.yaml`: Tier 3, 4, 5 operational limits (metadata only).
- `sensors/sensor_definitions.yaml`: Channel definitions, raw/canonical units, native rates.
