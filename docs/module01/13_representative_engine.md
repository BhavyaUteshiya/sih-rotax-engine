# Module 01 — Representative Reference Engine Profile

## Mandatory Disclaimer
> [!IMPORTANT]

## Profile Summary (`REPRESENTATIVE_REFERENCE_ENGINE`)
- Configuration: 4-cylinder, 4-stroke, turbocharged aero piston engine.
- Displacement: 1.35 Liters.
- Rated Power: 115 HP @ 5800 RPM.
- Demonstration Telemetry Channels: RPM, CHT (Cyl 1-4), EGT (Cyl 1-4), Oil Pressure, Oil Temperature, Fuel Flow, Vibration RMS, Battery Voltage, Alternator Current, Injection Timing.
