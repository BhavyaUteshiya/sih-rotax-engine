# Archived reference material

`old_project/` contains retired source, tests, configurations, and documentation from pre-Phase-0 implementations. It is **not authoritative**, is not part of the active test suite, and must never be imported by `src/digital_twin`.

The archive exists only to retain potentially useful historical parameter values, equations, references, and implementation context while preventing duplicate active systems. Curated lessons from it are recorded below and in the active documentation.
